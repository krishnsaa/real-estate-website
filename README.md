# 🏡 Real Estate Property Listing Platform

A modern **frontend-only web application** for showcasing **real estate properties** including **plots, flats, apartments, and commercial buildings**.  
This project focuses on **UI/UX, property browsing, and responsive design** for a real estate marketplace.

## ✨ Features

- 🏘️ Browse real estate properties  
- 🔍 Search & filter by:
  - Location  
  - Price range  
  - Property type (Plot / Flat / Building)  
- 📱 Fully responsive design  
- 🖼️ Image gallery for each property  
- ❤️ Wishlist / favourites (local storage)  
- 🎨 Clean and modern UI
